## 1. 复位与时钟

| # | 约束 | 出处 |
| --- | --- | --- |
| 1.1 | `reset` **高电平有效**；启动时框架保持高电平 **5 个周期** | README-ZH.md 顶层端口模板注释；sim.cpp `main()`（`for i<5 tick()` 期间 `reset=1`） |
| 1.2 | 复位期间从机所有 `ready`/`valid` 输出为 0，内部队列被清空 | sim.cpp `drive()`（`!top.reset && ...`）、`step()`（`if (top.reset) {...clear}`） |

| 1.4 | `clock` 为内存同步时钟，上升沿采样 | axi4-lite.md §2 |

## 2. 地址空间与对齐

| # | 约束 | 出处 |
| --- | --- | --- |
| 2.1 | 外部 RAM：**256 MiB 小端**，有效地址 `0x00000000`–`0x0fffffff` | README-ZH.md §内存布局；axi4-lite.md §6.1；sim.cpp `RAM_BYTES = 256*1024*1024` |
| 2.2 | 未加载的字节**默认清零** | axi4-lite.md §6.1；sim.cpp `bytes` 初始化为 0 |
| 2.3 | 32 位数据总线，读写地址必须**自然 4 字节对齐**（`addr[1:0]==2'b00`） | README-ZH.md §总线与内存约定；sim.cpp `response()` |
| 2.4 | 未对齐访问 → **SLVERR**；越界（`addr+4 > 256MiB` 且非退出地址）→ **DECERR** | axi4-lite.md §6.4；sim.cpp `response()` |
| 2.5 | 退出 MMIO 地址 `0x80000000` 在 RAM 之外，专用于终止 | axi4-lite.md §6.1；sim.cpp `EXIT_ADDRESS` |

## 3. 各通道队列与内存延迟模型

| # | 约束 | 出处 |
| --- | --- | --- |
| 3.1 | 从机在 AR、AW、W、R、B **五个通道各维护 16 项 FIFO** | README-ZH.md §总线与内存约定；axi4-lite.md §6.2；sim.cpp `DEPTH = 16` |
| 3.2 | 非复位且 FIFO 未满时，`arready/awready/wready` 恒为 1 | axi4-lite.md §6.2；sim.cpp `drive()` |
| 3.3 | 每个时钟周期**最多服务一个读请求和一个写请求**；读写同时就绪时顺序随机（伪随机决定谁先） | axi4-lite.md §6.2；sim.cpp `step()`（`write_first = random & 1`） |
| 3.4 | 请求在**握手成功的下一个周期**才进入服务流程 | axi4-lite.md §6.3；sim.cpp `step()`（服务在前、`push` 在后） |
| 3.5 | 从开始服务到响应可见固定 **10 周期**（`due = cycle + latency`，`--latency <N>` 可调，本地 `LATENCY=` 覆盖） | axi4-lite.md §6.3；README-ZH.md；sim.cpp `read()/write()` |
| 3.6 | 综合估算：**握手 → 数据可见 ≈ 1 + LATENCY 拍**（下一周期入队服务 + 延迟） | 由 3.4/3.5 推导 |
| 3.7 | 仿真周期上限默认 **1,000,000 拍**（`MAX_CYCLES` 可调），超时判 FAIL | config.mk；sim.cpp `limit` |
| 3.8 | CPU 每通道在飞请求必须 **< 16**（建议 ≤ 4~8），且**必须有能力接收所有响应**（`rready/bready` 及时拉高），否则队列堵死 | axi4-lite.md §3；sim.cpp 队列结构 |

## 4. 程序退出协议

| # | 约束 | 出处 |
| --- | --- | --- |
| 4.1 | 程序通过向 **`0x80000000`** 执行 **32 位 Store** 终止，必须 `WSTRB = 4'b1111`（`4'hf`） | README-ZH.md §终止约定；axi4-lite.md §6.5；sim.cpp `write()` |
| 4.2 | 退出返回值放在 **`WDATA[31:0]`** | 同上 |
| 4.3 | 仿真器在**写响应通道握手成功瞬间**（`bvalid && bready` 同拍为高）捕获返回值并结束仿真 | axi4-lite.md §6.5；sim.cpp `step()`（`if (b.front().exit) done = true`） |
| 4.4 | 向 `0x80000000` 写但 `wstrb != 4'hf` → **SLVERR 且不退出** | axi4-lite.md §6.4；sim.cpp `write()` |
| 4.5 | 退出 Store 的 B 握手完成前 CPU 不得停止应答（`bready` 必须保持直到 `exit_ack`） | 由 4.3 推导 |
| 4.6 | 正确性判定：最终返回值与标准答案**完全一致** | README-ZH.md §评分标准 |

## 5. AXI4-Lite 握手铁律

| # | 约束 | 出处 |
| --- | --- | --- |
| 5.1 | **Fire 条件**：同通道 `VALID && READY` 在**同一时钟上升沿**同时为高，事务才发生 | axi4-lite.md §3 |
| 5.2 | **VALID 稳定性**：`VALID` 拉高后保持到握手完成；伴随有效载荷（`ADDR/DATA/WSTRB`）在此期间不得改变 | axi4-lite.md §3 |
| 5.3 | **无组合环**：发送方 `VALID` 不得组合依赖对方 `READY`；接收方可先拉 `READY` 或等 `VALID` 再拉 | axi4-lite.md §3 |
| 5.4 | **AW 与 W 相互独立**：可同拍握手、AW 先或 W 先；**两者均握手成功后**从机才把请求压入队列处理 | axi4-lite.md §4.2 IMPORTANT；sim.cpp `do_write`（`!aw.empty() && !w.empty()`） |
| 5.5 | 建议（可视为个人规范）：保持 `awvalid` 与 `wvalid` 永远一致，避免错拍窗口 | axi4-lite.md §4.2 |
| 5.6 | `ARPROT/AWPROT` 未连接，可不声明或置 0 | axi4-lite.md §2 NOTE |
| 5.7 | 无突发（No Burst）：每次事务固定 32 位 | axi4-lite.md §1 |
| 5.8 | 响应码：`2'b00` OKAY；`2'b10` SLVERR（未对齐、非全掩码退出写）；`2'b11` DECERR（越界） | axi4-lite.md §6.4；sim.cpp |

## 6. sram_fakeram 时序与限制（片上 SRAM）

| # | 约束 | 出处 |
| --- | --- | --- |
| 6.1 | 参数：`DEPTH` 1..1,048,576；`WIDTH` 1..4,096；`WRITE_GRANULARITY` 1..WIDTH 且**整除 WIDTH** | sram.md §2；sram_fakeram.sv |
| 6.2 | 单实例容量上限：`DEPTH × WIDTH ≤ 16,777,216` 位（2 MiB） | sram.md §2 |
| 6.3 | **单端口 1RW**：每周期只能一读或一写（多端口需求要拆实例） | sram.md §3 |
| 6.4 | **同步读延迟 1 周期**：本拍 `en=1,we=0`，数据**下一拍**才在 `rdata` 有效 | sram.md §3 |
| 6.5 | `en=0` 或写周期（`we=1`）时 `rdata` **未定义**（不得读改写，写需用 `wmask` 合并） | sram.md §3 |
| 6.6 | `wmask` 位宽 = WIDTH/GRANULARITY；`WRITE_GRANULARITY=8` 时 32 位宽对应 4 位字节掩码 | sram.md §2/§3 |
| 6.7 | **无复位引脚**：内容上电未知；valid 位等需用寄存器复位清零 | sram.md §3 |
| 6.8 | 每次 `en=1` 时 `addr` 必须在 `[0, DEPTH-1]`，越界 `$fatal` 终止仿真 | sram.md §3；sram_fakeram.sv |
| 6.9 | **禁令**：不得把 `scripts/ram/sram_fakeram.sv` 加入 `filelist.f`（框架自动引入）；不得自写同名 stub；`sram_fakeram*`、`fakeram_asap7_*` 为保留前缀 | sram.md §1 IMPORTANT；build.py `with_ram_source()` |
| 6.10 | 面积模型：**0.0419904 μm²/位**（≈ 344 μm²/KiB），clock-to-q 随 DEPTH/WIDTH 增大，计入总面积 | scripts/fakeram.py `MODEL` |
